# FuFramework 踩坑记录索引

本文件是团队共享的 traps 索引，**进 git**。与个人自动记忆（`~/.claude/projects/.../memory/`）是两个不同的东西。

## 维护原则

1. **按业务域拆分**：规则写入对应 `traps-*.md`，**不写入本文件**。
2. **约束声明格式**：条目以「违反/必须」句式开头，见 `traps-authoring.md`。
3. **禁止重复**：`rules/` 已覆盖的稳定约定不写进 traps。
4. **禁止记录会话上下文**：只记可迁移的工程规律，不记任务状态、待办、本次改动。

## Token 阈值清理规则

任一 `traps-*.md` 超过 5000 token 触发清理，顺序：合并相似 → 删除已被 rules 覆盖 → 通用规律迁入 `rules/`。

## feature-map 维护原则

只做「功能 → 文件路径」索引；**禁止写实现细节与业务结论**。
