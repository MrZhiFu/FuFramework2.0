# 配置表诊断表

规范见 `rules/framework/config-tables.md`。本文件只做**症状 → 先查什么**。

| 症状 | 先查 |
|---|---|
| 某张表生成了，但代码里找不到对应类 | 表名分组段是否被脚本的 target 覆盖；脚本是否传了 `tableImporter.target` |
| 生成后同目录的手写文件消失 | 生成器是否开启了输出目录清理（应关闭） |
| 改了模板但生成结果没变 | 是否先重建了 Luban 工具 |
| 生成脚本本身报乱码/语法错 | 脚本内是否混入了非 ASCII 字面量 |
| 本地化表新增后生成直接中止 | 是否漏了 `is_code` 列 |
| 服务端生成的集合打印异常 | 是否用了 Luban 运行时工具类（服务端不引用它） |
| 枚举键做字典键报类型错 | 是否做了 `(long)` 强转 |
