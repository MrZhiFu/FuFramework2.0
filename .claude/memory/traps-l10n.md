# 本地化诊断表

规范见 `rules/framework/localization.md`。本文件只做**症状 → 先查什么**。

| 症状 | 先查 |
|---|---|
| 改表列后 AOT 界面文案错位/串行 | `ParseBin` 的读列顺序是否同步改了 |
| 同文件引入两个同名枚举报重定义 | 是否漏了 using 别名（AOT 与热更各有一份） |
| 切语言后下次启动 AOT 界面语言还是旧的 | 热更侧切语言时是否同步写了 AOT 侧偏好键 |
| 文案显示空白而不是 key 或原文 | 取词是否在中途返回空串，截断了回退链 |
| 缺翻译时显示的是 key 本身 | 正常（回退链最后一级），但若本应有英文则查英语列 |
| 语言切换后部分界面文本不刷新 | 是否漏了整界面刷新调用 |
| 输入框内容被语言刷新清空 | 是否给输入类组件绑了 L10n |
| AOT 启动界面空白 | `LaunchLocalization.InitializeAsync` 是否早于界面创建 |
