# 网络层诊断表

规范见 `rules/framework/network-protocol.md`。本文件只做**症状 → 先查什么**，不重复规则条文。

| 症状 | 先查 |
|---|---|
| 消息莫名没进注册表，无报错 | 导出器的消息/枚举正则是否用 `+` 而非 `*`（空消息体匹配不上） |
| 改了导出器行为没变化 | 是否先构建了导出器（导出脚本跑的是 bin 里的旧 dll） |
| 导出脚本跑完进程不退出 | 是否漏传 `ci` 参数（无参会在结尾等待输入） |
| 新增推送监听后永不触发 | 是否漏跑注册表生成（编译期守卫会报"声明与生成物不一致"） |
| 推送在断线重连后丢一段 | 派发阀门是否在"基线建立前挂起、拉全量后恢复" |
| 客户端收包分发表对不上 | 消息 ID 数值是否被改动（ID 是线上兼容契约，改了即断旧客户端） |
| 服务端/客户端类型不一致 | 两端生成物是否来自同一次导出 |
