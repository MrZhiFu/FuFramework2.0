# 工具链诊断表

规范见 `rules/tooling/`。本文件只做**症状 → 先查什么**。

| 症状 | 先查 |
|---|---|
| 读控制台第一次有数据，第二次全空 | 控制台读取是消费式的（读完即清零） |
| Play 中改代码/刷新资源报阻断 | 资源库操作在 Play 下被阻断，需先停 Play |
| 探针日志轮询一直空转 | 探针输出的实际级别被抬升（不是普通日志）；优先改用结果文件轮询 |
| 资源加载时序问题在编辑器里复现不出 | 编辑器模拟模式下加载恒约 1 帧，需切真实 PlayMode |
| 反射调用带可变参数的方法抛参数个数异常 | 可变参数需显式传空数组 |
| 新增菜单的排序不如预期 | 是否绕过优先级常量直接写了数字 |
| 批量改名后出现莫名的类型名缺失 | `-replace` 大小写不敏感；改用 `-creplace` 并立即编译验证 |
| 脚本里的中文变成乱码 | 无 BOM 脚本按 ANSI 读；字面量保持纯 ASCII |
| 文件末尾反复出现换行 diff | 项目约定文件末尾**不**加换行；不要"修复" |
