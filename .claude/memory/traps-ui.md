# UI / FairyGUI 诊断表

规范见 `rules/ui/fgui-workflow.md`。本文件只做**症状 → 先查什么**。

| 症状 | 先查 |
|---|---|
| 发布后列表取默认项时空引用（不是返回 null） | 新增组件 XML 是否未被编辑器导入（需重开工程）；扫 `_fui.bytes` 中组件名出现次数 |
| 新增控件的事件没接线 | 是否落在 Gen 层而非手写层（存量手写文件不会被覆盖） |
| 插件行为改了但编辑器里没变化 | 插件需重开编辑器才重载 |
| 界面层级显示顺序不对 | 层级枚举值与期望是否一致（值越大越靠前） |
| 列表项拖拽/重建后取错子对象 | 是否改用了索引取子对象（层级调整会静默错位） |
| 内存里包一直不释放 | 确认打包颗粒度，再判断销毁策略是否真的异常 |
| 切换语言后部分界面文本不变 | 是否漏了整界面刷新调用 |
