# UI 切图存放目录规则

## 目标

1. **减少发布变动范围**：按功能区分明确图集编号，使修改发布时只重编受影响的图集，避免牵连无关资源
2. **整理大图资源**：宽或高 >= 512px 的图片统一单独发布（alone_npot），不占用合图空间
3. **清理冗余资源**：识别并清除未使用、废弃、重复的切图，减小包体和图集浪费

## 核心规则

1. **一个文件夹 = 一种功能归类**：同一文件夹内的图服务于同一功能或同一类型，禁止混放不同用途的切图
2. **一个文件夹指定一个 atlas 编号**：确保类型内聚，修改只重编当前类型的图集
3. **大图单独发布**：宽或高 >= 512px 的图放 /Res/Single/，设 alone_npot
4. **禁止使用默认 auto**：每个包含图片的文件夹必须显式指定 atlas 编号或 alone_npot。如果包中图片较少，可直接放在Image目录下且不用指定atlas 编号，FGUI会默认自动分配。

## 目录结构规范

### 功能模块包（可不做细分，也可独立做细分，看图片数量，大于20张建议细分）

```
包名/
├── Res/
│   ├── Single/      ← 大图 (>=512px)，alone_npot 单独发布
│   ├── Custom/      ← 自定义细分名称，独立 atlas 编号
│   └── *.png        ← 小图直接放 Res/ 下，给 Res/ 指定独立 atlas 编号
└── ...
```

### Common 包（按组件类型细分）

```
Common/
├── Res/
│   ├── Single/          ← 大图 (>=512px)，alone_npot 单独发布
│   ├── Button/          ← 按钮切图，独立 atlas 编号
│   ├── Frame/           ← 窗体切图，独立 atlas 编号
│   ├── Progress/        ← 进度条切图，独立 atlas 编号
│   ├── Icon/            ← 图标切图，独立 atlas 编号
│   └── ...              ← 其他类型按需新建
└── ...
```

### Icon 包（按功能类型细分）

```
Icon/
├── Res/
│   ├── Single/          ← 大图 (>=512px)，alone_npot 单独发布
│   ├── Item/            ← 道具图标，独立 atlas 编号
│   ├── Build/           ← 建筑图标，独立 atlas 编号
│   ├── HeroFull/        ← 英雄全身像图标，独立 atlas 编号
│   ├── HeroHalf/        ← 英雄半身像图标，独立 atlas 编号
│   └── ...              ← 其他功能按需新建
└── ...
```
