# UI 模块重构：移除 ICustomComp，组件自持 Register — 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 移除 `ICustomComp` 接口和 `ViewBase.InitChildrenView()` 自动扫描，改为自定义组件在 `ConstructFromXML` / `Dispose` 中自持并管理 `FuiEventRegister`、`EventRegister`、`TimerRegister`。

**Architecture:** 修改 FairyGUI 代码生成器插件模板，让 `Comp*.Gen.cs` 的组件类自行创建三个 Register 并直接调用，不再持有 `uiView` 引用；同步清理 C# 侧的 `ICustomComp` 接口文件和 `ViewBase` 中的递归扫描方法。

**Tech Stack:** FairyGUI Editor Lua 插件 (CSharpCodeGen)、C# (.NET Standard 2.1 / Unity 2022.3)、FairyGUI 运行时

## Global Constraints

- 遵守 `Docs/代码风格规范.md`（m_ 前缀、XML 注释、#region 分组）
- 遵守 `Docs/Git提交规范.md`（Conventional Commits 中文版）
- 所有 UI 操作在主线程执行
- 不能修改 FairyGUI 运行时源码（`3rdPlugins/FairyGUI/Scripts/`）
- 手写 `Comp*.cs` 文件不受影响（生成器检测已存在即跳过）

```csharp
        /// <summary>
        /// 递归初始化自定义子组件，传递自身实例给子组件。
        /// 注：自定义子组件实现ICustomComp接口(已在导出FUI时自动实现了)
        /// </summary>
        private void InitChildrenView(GComponent curComp)
        {
            var children = curComp.GetChildren();
            foreach (var child in children)
            {
                var comp = child switch
                {
                    GLoader loader   => loader.component,
                    GComponent component => component,
                    _                    => null
                };

                if (comp is not ICustomComp customComp) continue;
                customComp.Init(this);
                InitChildrenView(comp);
            }
        }
```
