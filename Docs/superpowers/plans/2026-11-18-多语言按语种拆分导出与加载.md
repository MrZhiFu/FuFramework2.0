# 多语言按语种拆分导出与加载 — 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 本地化配置按语种拆分为 15 个产物文件，运行时只加载当前语种（+英语兜底），手动切换语言时经 AssetModule 通用下载能力按需拉取目标语种，就绪后才广播语言切换事件。

**Architecture:** Luban 导出后由 C# 工具把整表拆成 15 个语种文件（新目录 `Assets/Bundles/Localization`，YooAsset 15 个单文件收集器各打语种 tag）；AOT 首启下载器按语言 tag 过滤（YooAsset 原生语义：未打 tag 的 bundle 视为公共依赖始终包含，现有资源不受影响）；热更侧 loader 拦截 `tblocalization` 表名路由到当前语言文件（生成代码零改动）；`LocalizationModule.SetLanguageAsync` 编排 下载→原地重填→广播，事件时序保证业务表重译不落后。

**Tech Stack:** Unity 2022+ / UniTask / Luban（自改源码版）/ YooAsset 3.0.5 / HybridCLR / .NET 8 console 工具

**Spec:** `Docs/superpowers/specs/2026-11-18-多语言按语种拆分导出与加载-design.md`

## Review Focus

1. **切换中途失败的中间态**：`SetLanguageAsync` 下载/加载失败时 `m_language` 已改、表数据未换 → `GetLanguageText` 按 switch 新语言取到空串回退 English，界面语言错乱。期望：失败必须回滚 `m_language` 到旧值并返回 false。→ Task 8 步骤 1 的探针断言。
2. **事件时序倒挂**：`LanguageChangeEventArgs` 广播早于表重填 → `TableManager.RefreshTranslateText` 拿旧表重译，业务表翻成旧语言。期望：重填完成后才广播。→ Task 8 步骤 3 探针断言（切语言后读业务表行字段）。
3. **bin/json 变体混跑残留**：先跑 bin 再跑 json，`Bundles/Localization` 下两套产物共存被同时打包。期望：拆分工具清理非当前变体。→ Task 2 步骤 2 验证。
4. **加载中重复切换**：切换 A 进行中又点切换 B → A 链路必须被取消（旧 token 取消后 A 不广播不存档），最终停在 B。期望：防抖以最新目标为准。→ Task 8 步骤 4 探针断言。
5. **AOT 首启 tag 过滤漏下公共依赖**：tag 过滤若把未打 tag 的公共 bundle 漏掉 → 首启后资源缺失。已验证 YooAsset 3.0.5 `FileSystemHost.cs:424` 未打 tag bundle 始终包含；实施后须真机/模拟器首启验证清单。→ Task 10 步骤 3。

`LocalizationModule` 追加（ setter 内的存档+回写+广播三步抽成私有方法 `ApplyLanguageChange(ELanguage oldLanguage, ELanguage newLanguage)` 供 setter 与 SetLanguageAsync 共用；**注意 setter 的 `if (value == m_language) return;` 提前返回逻辑保留在 setter 内，SetLanguageAsync 走自己的同语言短路**）：

```csharp
/// <summary>
/// 异步切换语言：确保目标语种资源就绪（必要时下载）→ 重填本地化表 → 才持久化并广播语言切换事件。
/// 加载/下载中再次切换会取消旧链路，以最新目标为准；失败回滚内存语言并返回 false（不广播不存档）。
/// </summary>
public async UniTask<bool> SetLanguageAsync(ELanguage language, CancellationToken token)
{
    if (language == ELanguage.Unspecified) { FuLogger.LogError("..."); return false; }
    if (language == m_language) return true;
    m_barrier.Token.ThrowIfCancellationRequested();
    token.ThrowIfCancellationRequested();

    var oldLanguage = m_language;
    m_language = language; // 先改内存语言：loader 路由与 AssetModule 按 tag 下载都读它
    using (m_barrier.Begin())
    using (var linkedCts = CancellationTokenSource.CreateLinkedTokenSource(m_barrier.Token, token))
    {
        try
        {
            // 1. 下载目标语种 bundle（本地已有则直过；失败回滚返回）
            if (!await GlobalModule.AssetModule.EnsureDownloadByTagAsync(language.ToString(), linkedCts.Token))
            {
                m_language = oldLanguage;
                return false;
            }

            // 2. 重填本地化表（loader 此时路由到新语言文件）；重填失败同样回滚
            if (LocalizationReloader == null) { FuLogger.LogError("本地化表重填回调未注入"); m_language = oldLanguage; return false; }
            await LocalizationReloader(linkedCts.Token);

            // 3. 表就绪后才持久化 + 广播（TableManager 订阅者此时重译拿到的已是新表）
            ApplyLanguageChange(oldLanguage, language);
            return true;
        }
        catch (OperationCanceledException)
        {
            m_language = oldLanguage; // 取消链路回滚内存语言（数据未换，必须还原）
            throw;
        }
        catch (Exception e)
        {
            FuLogger.LogError($"切换语言 {language} 失败：{e.Message}");
            m_language = oldLanguage;
            return false;
        }
    }
}
```
