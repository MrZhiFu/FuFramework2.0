# 多语言拆分并入 Luban 与字段剥离（v3 第二期）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 拆分逻辑并入 Luban 管线（PostProcess），产物剥离 is_code 与 json 冗余语种字段（json 2 键 / bin 16 字段），运行时英语兜底改为二次查英语表（懒加载）。

**Architecture:** Luban 新增 `[PostProcess("split-localization")]` 处理器：从 `GenerationContext` 原始 Record 逐语种写 15 个产物文件进 manifest、删除整表文件（整表不再落盘）；`is_code` 列经 Excel `##group` 标记剥离（`ExportFields` 同时驱动数据写出与代码生成，两端自动一致）；json 变体产物 2 键 → 生成模板对 Localization bean 加宽容反序列化分支（缺键→null，普通表严格性不波及）；bin 变体产物保持 16 字段顺序序（key + 15 语种，目标语种有值其余空串）→ 模板零改动列序稳定；`LocalizationProvider` 查询 miss 后二次查英语表（HotfixLauncher 注入显式英语 loader，懒加载 + 并发防护）。

**Tech Stack:** Luban 自改源码（net8.0，scriban 模板）/ Unity 2022 + UniTask / YooAsset 3.0.5（沿用 v2 收集配置）

**Spec:** `Docs/superpowers/specs/2026-11-20-多语言拆分并入Luban与字段剥离-design.md`

- [ ] **Step 1: CsharpSimpleJsonTemplateExtension 加 DeserializeLenient**

```csharp
/// <summary>
/// 本地化拆分产物专用宽容反序列化：缺键（或 null 值）时字段置 null，不抛 SerializationException。
/// 仅限 Localization bean 的语种字段（模板分支控制）；key 字段不经过此函数（保持严格）。
/// </summary>
public static string DeserializeLenient(string fieldName, string jsonVar, string jsonFieldName, TType type)
{
    // type 恒为 TString（模板分支保证）；缺键返回 JSONNode.Null 实例（SimpleJSON indexer 行为），IsString=false → null
    return $"{{ var _j = {jsonVar}[\"{jsonFieldName}\"]; {fieldName} = _j.IsString ? _j.Value : null; }}";
}
```

- [ ] **Step 2: bean.sbn 反序列化构造加分支**

`cs-simple-json/bean.sbn` 反序列化构造（约 :192-195 字段循环）内，`{{deserialize_field ...}}` 处改为：

```scriban
{{~if __bean.name == 'Localization' && field.type == 'string' && field.name != 'key'~}}
{{DeserializeLenient fieldName 'node' field.name field.ctype}}
{{~else~}}
{{deserialize_field fieldName 'node' field.name field.ctype}}
{{~end~}}
```

（`DeserializeLenient` 经模板上下文可直接调——`CsharpSimpleJsonTemplateExtension` 已 push 进 ctx；若函数不可达则在模板 `{{~func~}}` 内转调或检查 `OnCreateTemplateContext` 的 push 机制。）
