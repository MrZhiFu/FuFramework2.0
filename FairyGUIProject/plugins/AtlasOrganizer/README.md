
# AtlasOrganizer - 图集整理工具

FairyGUI 编辑器插件，用于 UI 图集的诊断、整理和清理。

## 功能清单

| 功能               | 说明                                                                        |
| ------------------ | --------------------------------------------------------------------------- |
| 清理空文件夹       | 扫描并删除所有包中的空文件夹                                                |
| 扫描重复图片       | 基于 MD5 检测跨包重复图片，输出重复分布报告（清理由「一键清理重复图片」承担） |
| 一键合并同文件重复ID | 自动合并指向同一物理文件的重复条目（不同 ID），保留引用最多的条目、改写引用并删除其余 |
| 一键清理重复图片   | 基于 MD5 一键合并内容重复的图片：同包组自动合并，跨包组收拢到 Common/Res 并设置导出 |
| 扫描未引用资源     | 检测全局未被组件/动画引用的图片/Sprite（导出豁免），输出分布报告             |
| 一键清理未引用资源 | 自动删除扫描出的未引用资源，同文件多 ID 时保护被引用条目                     |
| 扫描大图 (>=512px) | 找出未放入 /Res/Single/ 的大尺寸图片，一键移动到 /Res/Single/ 并设为 alone_npot |
| 图集优化分析       | 诊断混用（被其他包引用）、分散（组件引用 3+ 图集）、未分配（默认 auto）问题 |

## 使用方式

菜单路径：**工具 → 图集整理**

### 同文件重复ID工作流

1. 执行「一键合并同文件重复ID」
2. 自动按物理文件分组，组内保留引用最多/已导出的条目，其余条目的引用改写到保留项后删除
3. 控制台输出每组明细（保留 ID、合并映射）与汇总统计

与「扫描重复图片」的区别：后者针对 MD5 相同但物理文件不同的冗余图片，需人工逐组确认；本功能针对不同 ID 指向同一物理文件的条目，可一键自动合并。删除条目时保留共享的物理文件，避免保留条目失图。

### 一键清理重复图片工作流

1. 执行「一键清理重复图片」
2. 自动按图片内容 MD5 分组处理：
   - **同包组**：保留引用最多/已导出的条目，其余条目引用改写后删除
   - **跨包组**：图片收拢到 Common 包的 /Res/ 并设置导出，各包引用统一改指 Common（组内已有 Common 条目则直接归位使用，否则从源文件导入）
3. 控制台输出每组明细与汇总统计

与「一键合并同文件重复ID」的区别：后者合并同一物理文件的多个 ID 条目；本功能合并内容相同（MD5 一致）但物理文件不同的图片，并负责跨包归一到 Common。

### 未引用资源工作流

1. 执行「扫描未引用资源」审计未引用分布
2. 执行「一键清理未引用资源」自动删除（导出资源豁免，不会被删除）

### 大图整理工作流

1. 执行「扫描大图」审计需整理的大图分布
2. 执行「一键整理大图」：移动到 /Res/Single/ 并设置 alone_npot，清理空源文件夹

### 图集优化分析

执行后在控制台输出诊断报告，包含三类问题：

- **混用问题**：图片被其他包的组件引用（Common/Icon 包除外），导致修改时重编不相关图集
- **分散问题**：单个组件引用 3 个以上不同图集编号，造成额外 DrawCall
- **未分配图集**：文件夹未指定 atlas 编号，使用默认 auto

## 文件结构

```
AtlasOrganizer/
├── main.lua                      ← 插件入口（菜单注册、模块加载、生命周期）
├── src/
│   ├── utils.lua                 ← 公共工具函数
│   ├── clean_empty_folders.lua   ← 功能1: 清理空文件夹
│   ├── scan_duplicate.lua        ← 功能2: 扫描重复图片
│   ├── scan_merge.lua            ← 功能6: 一键合并同文件重复ID
│   ├── clean_duplicate.lua       ← 功能7: 一键清理重复图片
│   ├── scan_unused.lua           ← 功能3: 扫描未引用资源
│   ├── scan_large.lua            ← 功能4: 扫描大图
│   └── analyze_atlas.lua         ← 功能5: 图集优化分析
├── package.json                  ← 插件描述
├── atlas_rules.md                ← 图集目录存放规范（交付美术）
└── README.md                     ← 本文件
```
